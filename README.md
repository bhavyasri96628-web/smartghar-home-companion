# Smartghar Home Companion

Build a modern, beginner-friendly website called SmartGhar AI Home Helper.

The website should help families solve everyday household problems.

Features:

AI Home Assistant: A chat interface where users can type home-related questions and receive helpful answers.

Electricity Saving: Practical tips to reduce electricity bills.

Cleaning Assistant: Easy household cleaning tips and routines.

Cooking Assistant: Suggest recipes based on ingredients available at home.

Home Organization: Help users organize rooms and manage household chores.

Design:

Modern, clean, responsive design.

Use a green and white color theme.

Add a home-themed header, attractive feature cards, icons, and a chat box.

Make it easy to use on mobile phones and laptops.

Functionality:

All buttons and input fields must work.

Show helpful responses to home-related questions.

Use an AI API securely on the server side for real AI-generated responses. Never expose API keys in frontend code.

If no AI API is configured, provide useful predefined responses and clearly indicate that live AI is not connected.

Include loading indicators and friendly error messages.

Build and test the working website, not just a visual mockup. Explain any API setup required.
